# Power BI Sales Analysis Dashboard

## Overview
An interactive Sales Analysis Dashboard built in Power BI for Haldyn Heinz Fine Glass manufacturing company.

## Dashboard Pages
- Welcome Page
- Sales Overview
- Profit Analysis
- Time Series Analysis
- Region Wise Analysis
- Customer Analysis
- Detailed Customer Analysis

## Tools Used
- Power BI Desktop
- DAX
- Power Query
- Excel/CSV Data
